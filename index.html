Where this comes from, and what it leaves out

Source: World Bank Open Data, 2023 only — every figure in this table is for the same year, taken from the World Bank API:

  • Health spending per person, current US$ — SH.XPD.CHEX.PC.CD
  • Life expectancy at birth, total (years) — SP.DYN.LE00.IN
  • Population — SP.POP.TOTL

Any single row can be re-checked against the API in a browser, for example the 2023 figure for the United States (swap the country code and the indicator code in that URL). Full notes, including every cleaning decision, are in README.md.

The important caveat: everything here is a national average. A single number per country hides who within it gets the care. The country with the highest average life expectancy in this dataset can still have enormous internal gaps. Seeing a clean trend in a scatter plot is exactly the moment to ask what the average is concealing.
